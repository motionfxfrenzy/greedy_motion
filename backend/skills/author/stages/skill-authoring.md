# New reusable style or skill

Use the repository's gm-skill-authoring procedure for slot schema, factual inputs, frozen template, sample values, visual gates and versioning. Use the design references for clear scene direction. A new style requires a catalog entry, source/reference assets with provenance, a preview that represents actual output, a render path and checks. Review third-party material before incorporating it; stage prompts and bundled artifacts are regenerated in CI.

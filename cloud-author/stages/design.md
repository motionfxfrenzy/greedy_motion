# Scene design

Define one visual idea per scene: subject, spatial hierarchy, palette from the brand, type scale, safe areas for each aspect ratio and the role of motion. Use the design references to choose a coherent treatment. An interaction pattern should become a state machine only when the viewer can actually control it. Pass a concrete scene specification into the composition stage.

Design for the format it is in: 9:16 means fewer simultaneous elements, one idea per frame, a stronger vertical hierarchy and larger type, with nothing important in the top 13% or bottom 22% of the frame; 1:1 means tighter type and shorter holds; 16:9 may carry more spatial context. The last frame must work as a poster (mark and call to action readable, one focal point). Keep every read-at-rest element inside the title-safe box (10% inset).

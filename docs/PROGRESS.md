## Container validation sequence

1. Build `videosaas-renderer:local` from the repository root using the renderer Dockerfile.
2. Run the image with no network and execute `node src/self-test.mjs`.
3. Assert the emitted JSON reports a successful lint/check/render/probe with H.264, 1920×1080, 30 fps, and 180 frames.
4. Run the normal worker process and verify `/healthz` and `/readyz` on its configured `PORT`.
5. Inspect the image: Node 24, Chromium, FFmpeg, HyperFrames 0.8.111, GSAP 3.14.2, bundled font, and non-root user.
6. Record image size, render seconds, peak memory, output bytes, and any network attempt in `docs/LOCAL_VALIDATION.md`.
7. Only then move CONT-01 to complete. It is still separate from M4 `RENDER-03`, which requires Railway staging deployment and benchmark data.

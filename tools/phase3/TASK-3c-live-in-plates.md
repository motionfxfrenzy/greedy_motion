## What to build
1. **A stage component for live scenes** inside `PlatePreview` (new file under `frontend/components/`, not inside `animation-workspace/`): renders the `createFilmPlayer` canvas in `renderStage()`, driven by the workspace's play/pause/seek/volume state. **Audio stays the master clock**: reuse the existing voice, music and effects audio elements and `PlaybackClock`; the stage asks the clock for the frame; a frame not yet drawn keeps the previous one and shows the buffering indicator the shell already has. Subtitles and other overlays keep working exactly as today (they sit above the stage).
2. **Per-scene mode.** For every scene of the viewed aspect, the player decides live or clip (`decision()` of the 2b player: gate, host health, environment verified or not). Live needs: flag on, project `mode === "live"`, variant state `bundled` or `checked` or `drawn` with a bundle. A scene that is not live is shown from its clip; if it has no clip yet, request one with `requestClip` (surface a 429 `clip_cap` as a calm "preview video is queued" state, never an error) and show the scene's still or reference frame meanwhile. Switching between a live scene and a clip scene at a scene boundary must not flash or stall.
3. **The check flow.** For each live-eligible scene: `fetchBundle` then `runCheck` then `reportCheck` (fenced; a 204 is fine), once per `(variant, gen, bundleDigest)`; failures of kind `env` fall back to the clip, kind `code` is reported and the existing repair path runs (the UI shows "updating" on that scene's tab, as it does for plates being redrawn today).
4. **Status and prep.** Map the live states onto the shell's existing prep/ready/updating indicators: a scene counts as ready when it is `checked` (live) or `drawn` (clip). No new UI elements, no new copy except where listed below. The status chip may say "n/5 ready".
5. **Comments, apply, render, aspects, final page:** unchanged behaviour (comments call the existing apply path; Render uses the existing flow; `PlateFinal` is untouched). Aspect switching loads that aspect's variants the same way.
6. **Clean-up and limits:** one `createFilmPlayer` per mounted workspace; destroy it on unmount, aspect change and project change (no leaked Workers, iframes, bitmaps: prove with a test that counts iframes and Workers before and after); respect the cache budget from 2b; honour `prefers-reduced-motion` (no change needed unless the existing UI does something).
7. **Flag and dev aids:** `NEXT_PUBLIC_PLATE_LIVE` read once in one small module (`frontend/lib/live/flag.ts`); a visible-only-in-dev line is allowed in `frontend/app/dev/plate-preview-fixture/` (not in the product UI) showing per-scene mode and reasons.
